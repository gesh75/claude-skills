# Email Ghostwriter

## Email Anatomy
```
Subject:  <50 chars | one clear benefit or question
Preview:  extends subject — don't repeat it
Line 1:   context or hook (1 sentence)
Body:     the ask or message (2–4 sentences max)
CTA:      one clear next step
Sign-off: match formality to relationship
```

## Templates by Situation

**Bad news / missed deadline**
```
Subject: [Project] — Update + next steps
[What happened, 1 sentence]. [Impact, 1 sentence].
Here's what I'm doing to fix it: [action].
I'll have [deliverable] to you by [date]. Let me know if you'd like to discuss.
```

**Cold outreach**
```
Subject: [Specific result] for [their company]
[Personalized observation about them — 1 sentence].
[What you do + relevant proof — 1 sentence].
[Specific offer with low-friction ask — 1 sentence].
Worth a 15-min call this week?
```

**Negotiation / counter-offer**
```
Subject: Re: [offer/proposal]
Thank you for [offer]. I'm very interested in [thing].
Based on [market data / my experience / competing offer], I was expecting [X].
Is there flexibility to [specific ask]? I'm committed to making this work.
```

**Follow-up (no response)**
```
Subject: Re: [original subject]
Following up on my note from [date].
[One-line reminder of the ask].
Happy to make it easier — [alternative format/timing].
```

**Setting a boundary**
```
[Acknowledge the request].
I'm not able to [thing] because [brief reason].
What I can do is [alternative].
```

## Tone Guide
| Situation | Tone | Avoid |
|---|---|---|
| Executive / C-suite | Direct, concise, no hedging | "Just wanted to..." |
| Peer / colleague | Warm but clear | Over-apologizing |
| Client / customer | Professional + empathetic | Jargon |
| Conflict / complaint | Calm, factual, solution-focused | Defensive language |
