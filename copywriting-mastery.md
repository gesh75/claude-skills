# Copywriting Mastery

**Rule**: Sell the outcome, not the feature. Use the customer's words, not yours.

## Frameworks
| Framework | Structure | Best for |
|---|---|---|
| AIDA | Attention → Interest → Desire → Action | Ads, emails, landing pages |
| PAS | Problem → Agitate → Solve | Cold outreach, sales pages |
| BAB | Before → After → Bridge | Testimonials, case studies |

## Headline Formulas
```
How to [result] without [pain]
[N] ways to [goal] in [timeframe]
Stop [wrong thing]. Start [right thing].
[Result] in [timeframe] — guaranteed
Warning: [consequence of inaction]
```

## Features → Benefits
```
Feature + "which means you can..." = Benefit
1-click import → Up and running in 2 minutes, no IT needed
256-bit encryption → Safe even if our servers are hacked
```

## VoC Mining
- Read competitor 1-star + 5-star reviews — steal exact phrases
- Mine support tickets
- Ask customers: "What were you trying to do when you found us?"

## Landing Page Structure
1. Headline: biggest benefit or pain solved
2. Subhead: who it's for + how (1 sentence)
3. Hero CTA: verb + outcome ("Start saving time")
4. Social proof: 3 testimonials with specific results
5. Benefit bullets: benefit first, feature second
6. Objection handling / risk reversal
7. Repeat CTA

## Email Subjects
- <50 chars, curiosity gap OR direct benefit (not both)
- Avoid: spam triggers, excessive caps, "click now"
